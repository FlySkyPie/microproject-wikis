**PEP (Python Enhancement Proposals)** 是 Python 社群的核心技術文件系統，負責引導語言的演進。

-   **功能：** 每份 PEP 都是一份技術規格書。舉凡新語法特性（如 `async/await`）、標準庫變更，甚至是社群治理架構，都必須透過 PEP 提案。

-   **代表性 PEP：**

    -   **PEP 8：** 著名的程式碼風格指南。

    -   **PEP 20：** 「The Zen of Python」（Python 之禪）。

-   **流程：** 由作者提交草案，經社群公開討論與審核，最終由指導委員會（Steering Council）決定是否採納。

簡言之，PEP 確保了 Python 在去中心化的開發環境中，仍能維持嚴謹的技術標準與設計一致性。
