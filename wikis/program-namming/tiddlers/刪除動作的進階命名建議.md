- **資料庫相關**
  - `drop`：刪除資料庫物件（如 Table）。
  - `truncate`：截短。在 SQL 中指清空資料表但保留結構。
- **資源管理**
  - `free` / `release`：釋放系統資源。
  - `dispose`：妥善處理並銷毀物件。
- **強烈語氣/不可逆動作**
  - `destroy`：暗示不可逆的毀滅，常與 "soft delete"（可還原刪除）做區隔。
  - `purge`：強制驅離，可理解為「強制執行 delete」。
- **修剪與截斷**
  - `trim` / `prune`：修剪。與 `delete` 的差別在於這兩者偏向「消除部分」而非全部刪除。
- **程序終止**
  - `kill` / `terminate`：常用於終止作業系統中的 Process。
