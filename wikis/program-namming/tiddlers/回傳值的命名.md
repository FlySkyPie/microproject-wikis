為函式或程序的「回傳值」命名時，有以下常見選項：

- **ret / retVal / returnValue**：
  - 源自組合語言指令 `RET` (Return from procedure)。
  - 是通用的回傳值預留命名。
- **result**：
  - 常見於現代框架 (如 ASP.NET 的 `IActionResult`)。
  - 用於代表特定操作的「結果」。
- **特定語意情景命名**：
  - 根據運算性質命名：`answer` (答案)、`sum` / `total` (總和)、`average` / `mean` (平均)。
  - 根據方法名稱命名：例如 `GetStorageQuota()` 回傳 `quota`；`GetBookTitle()` 回傳 `title`。
