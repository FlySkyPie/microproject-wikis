antirez 將註解分為 9 大類，並區分其價值：
* **具正面價值**：
  * [Function comments](<#Function comments>)：介面與 API 說明。
  * [Design comments](<#Design comments>)：設計藍圖。
  * [Why comments](<#Why comments>)：解釋意圖與原因。
  * [Teacher comments](<#Teacher comments>)：解釋領域知識或數學公式。
  * [Checklist comments](<#Checklist comments>)：警示地雷與技術細節。
  * [Guide comments](<#Guide comments>)：導讀性質。
* **有疑慮或負面價值**：
  * [Trivial comments](<#Trivial comments>)：解釋不言自明之事。
  * [Debt comments](<#Debt comments>)：記錄技術債（應使用 Issue 系統）。
  * [Backup comments](<#Backup comments>)：備份舊程式碼用。
